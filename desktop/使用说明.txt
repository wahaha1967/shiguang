拾光自习室 · Windows 桌面版 使用说明

1. 双击“拾光自习室.exe”即可开始使用。
   首次运行如果 Windows 提示“未知发布者”，点击“更多信息 → 仍要运行”。
   程序只打开一个窗口，不会占用浏览器标签页。

2. 数据保存在：
   %USERPROFILE%\.local\share\shiguang-study
   卸载或删除 exe 不会删除这个目录；如需彻底清除，请手动删除该目录。

3. 备份与恢复：
   通过应用内“偏好与数据”完成导出和导入。导出的备份不包含 API Key。

4. AI Key 只保存在本机，并以密文形式存放在上述数据目录中。
   请勿把整个数据目录（尤其是 .env 和 study.db）分享给他人。
   AI Key 不会出现在页面、备份或日志中；删除 Key 后立即失效。

5. 应用只监听本机 127.0.0.1，没有账号体系。
   不要把它通过端口转发、内网穿透等方式暴露到公网。

6. 如果双击后提示“拾光自习室已经在运行”，请切换到已经打开的窗口。
   同一时间只允许运行一个实例，避免两个窗口同时修改数据。

7. 需要 Edge WebView2 运行库（Windows 11 自带，Windows 10 多数已安装）。
   若窗口空白并提示缺少 WebView2，请安装微软官方的 WebView2 Runtime 后重试。

8. 本版本与旧版 Python 版使用相同的数据目录和数据库格式，
   可以直接读取旧数据；首次打开旧数据库会自动完成兼容迁移。
   如果旧版把 .env 放在项目目录里，请先把它复制到数据目录，
   否则此前保存的 AI Key 无法解密，需要重新填写。
